## Eclipse Import 방법

1. Eclipse 실행
2. File > Import
3. General > Existing Projects into Workspace 선택
4. Select archive file 또는 Select root directory 선택
5. Week03 전체 폴더 또는 원하는 개별 프로젝트 선택
6. Finish 클릭
7. Package Explorer에서 프로젝트 확인
8. src 아래의 main 클래스 실행
