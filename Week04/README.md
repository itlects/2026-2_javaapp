# Week04 - Swing Data Management + Java File I/O

## 학습 주제
- 다양한 Swing 컴포넌트의 데이터 입력 활용
- JTable / DefaultTableModel
- JTable 행 추가·수정·삭제
- JTable 선택 이벤트와 상세 입력 폼 연동
- 검색/필터가 있는 회원목록 화면 설계
- 회원 데이터 관리 화면 CRUD 구현
- java.io 기반 텍스트 파일 읽기/쓰기
- BufferedReader / BufferedWriter
- FileReader / FileWriter
- try-with-resources
- JFileChooser를 이용한 GUI 파일 선택
- Swing 이벤트와 파일 입출력 연결

## 4주차 핵심 흐름

Swing 입력 컴포넌트 → DefaultTableModel → JTable → 선택 이벤트 → 등록/수정/삭제 → 검색/필터 → 파일 저장/불러오기 → 이후 JDBC/MySQL 연계
