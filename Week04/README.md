# Week04 - Java File I/O + Swing GUI

## 학습 주제
- java.io 기반 텍스트 파일 읽기/쓰기
- BufferedReader / BufferedWriter
- FileReader / FileWriter
- try-with-resources
- JFileChooser를 이용한 GUI 파일 선택
- Swing 이벤트와 파일 입출력 연결
