# JAVA 응용 2주차 — Swing 컴포넌트와 WindowBuilder

## 가져오기

1. Eclipse에서 **File → Import → General → Existing Projects into Workspace**
2. 이 폴더를 선택하고 **Finish**
3. src/week02에서 예제를 번호 순서대로 실행

## 예제 순서

| 번호 | 클래스 | 학습 내용 |
|---|---|---|
| 01 | Ex01JFrameBasic | JFrame 기본 창 |
| 02 | Ex02JPanel | JPanel로 영역 묶기 |
| 03 | Ex03LabelTextButton | JLabel, JTextField, JButton |
| 04 | Ex04SelectionComponents | JRadioButton, JCheckBox, JComboBox |
| 05 | Ex05FlowLayout | FlowLayout |
| 06 | Ex06BorderLayout | BorderLayout |
| 07 | Ex07GridLayout | GridLayout |
| 08 | Ex08ComponentGalleryWB | WindowBuilder 컴포넌트 예제 |
| 09 | Ex09SignupForm | Layout Manager로 회원가입 화면 작성 |
| 10 | Ex10SignupFormWB | WindowBuilder로 회원가입 화면 작성 |

## WindowBuilder

Eclipse Marketplace에서 **WindowBuilder**를 검색하여 설치합니다. 설치 후
**File → New → Other → WindowBuilder → Swing Designer → JFrame**으로 클래스를 생성합니다.
Ex08ComponentGalleryWB와 Ex10SignupFormWB는 WindowBuilder의 Design 탭에서 열어
배치와 속성을 확인할 수 있습니다.

> JDK 17 이상 권장. 외부 라이브러리는 필요하지 않습니다.
