# Week06_Workbook01_MemberCRUD — 회원관리 DAO 직접 완성

`MemberDAO`의 TODO 1~5(findAll, findById, insert, update, delete)가 비어 있습니다. GUI는 완성되어 있습니다.

1. TODO 하나를 완성할 때마다 `MemberDaoChecker`를 실행하여 [PASS]를 확인합니다.
2. 5개가 모두 PASS이면 `MemberManagementFrame`을 실행하여 등록 → 조회 → 수정 → 조회 → 삭제 → 조회 순서로 확인합니다.

점검 프로그램은 900번 회원(check900)으로 테스트하고 끝나면 지웁니다.
