## 2. 이론

### 기말평가 범위

Lect16 기말고사: JAVA 응용프로그램 개발능력 종합 평가. JSP·Servlet·MySQL 중심으로 각자 준비한 프로젝트를 시연하고 발표한다.

| 계층 | 설명할 내용 | 제시할 증거 |
|---|---|---|
| JSP | 입력 폼, 목록, 메시지, 출력 이스케이프 | 실제 화면과 JSP 소스 |
| Servlet | URL 매핑, GET/POST, 입력 검증, 전달/리다이렉트 | 요청 처리 메서드 |
| DAO/JDBC | PreparedStatement, 자원 해제, CRUD | DAO와 SQL |
| MySQL | PK, 제약조건, 테이블 관계 또는 설계 이유 | ERD와 SELECT 결과 |
| 통합 | 브라우저 요청부터 DB 저장과 화면 갱신까지 | 시연 및 요청 흐름 설명 |

GET은 조회에, POST는 데이터 변경에 사용한다. 입력 검증은 서버에서도 수행한다. SQL 값은 바인딩하고, 화면에 표시할 사용자 입력은 이스케이프한다. 저장 후 리다이렉트하면 새로고침에 의한 중복 제출을 줄일 수 있다.

## 4. 실습 및 과제

### 개인 프로젝트 시연 준비

1. 프로젝트 목적, 사용 대상, 핵심 기능을 한 문장씩 정리한다.
2. 제출본을 새 폴더에 풀어 README만 보고 실행할 수 있는지 점검한다.
3. schema.sql과 seed.sql로 DB를 재현한다. 기존 데이터 삭제가 필요한 경우 별도로 명시한다.
4. 목록 조회 → 등록 → 수정 → 삭제 → 검색 → 오류 입력 순서로 시연한다. 주요 기능이 다른 프로젝트는 그에 맞는 사용자 시나리오로 바꾼다.
5. 등록 직후 Workbench SELECT 결과와 화면 결과를 비교한다. 서버 재시작 후에도 데이터가 남는지 확인한다.
6. JSP → Servlet → DAO → MySQL 흐름을 실제 소스의 메서드와 연결해 설명한다.
7. 직접 구현한 부분, 참고한 자료/AI 도움, 해결한 오류와 남은 개선점을 구분한다.

개인별 발표 7분 + 질의응답 3분을 기본 운영안으로 제안한다. 실제 시간·순서·제출 기한은 교수자가 별도 공지한다.
