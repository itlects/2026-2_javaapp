# 10주차 JSP 기초 보충 실습

Actions / Implicit Objects / Client Request / HTTP Status / Form Processing.

Eclipse Enterprise 2025-09 + JDK 21 + Tomcat 10.1, UTF-8. DB·외부 라이브러리 없이 실행합니다.

1. Maven Existing Projects로 이 폴더를 Import합니다.
2. Context root jsp-foundations / Java 21 / Web Module 6.0 / Tomcat 10.1을 확인합니다.
3. Run on Server 후 http://localhost:8080/jsp-foundations/index.jsp를 엽니다.
4. docs/index.md의 환경·공통 파일부터 시작하여 01~05를 따릅니다.

JSP 스크립틀릿은 기초 동작 관찰용이며 기존 Servlet Controller 기반 로그인과 구별합니다. 참고 글의 과거 javax·플러그인·고정 GET 길이 등은 docs에서 현재 수업 기준으로 보완했습니다.
